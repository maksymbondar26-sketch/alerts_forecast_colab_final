# Прогноз повітряних тривог в Україні (Time Series Forecasting)

Пет-проєкт у рамках технічного відбору (Stage 2): побудова пайплайну прогнозування повітряних тривог із суворим запобіганням витоку даних (No Data Leakage).

## Структура репозиторію
- `alerts_forecast_colab_final.ipynb` — основний Google Colab ноутбук, у якому зібрано весь код, пайплайн, тести та графіки.
- Модулі проєкту вбудовані безпосередньо в середовище виконання ноутбука (робоча архітектура з модульною структурою: `events.py`, `features.py`, `labels.py`, `models.py`, `pipeline.py` тощо).

## Як запустити
1. Перейдіть за посиланням на цей репозиторій та завантажте файл ноутбука `alerts_forecast_colab_final.ipynb` (або відкрийте його безпосередньо через [Google Colab](https://colab.research.google.com/)).
2. Підключіть Google Drive (ноутбук автоматично створить потрібну структуру тек у `Google Drive/alerts-forecast/`).
3. Виконуйте клітинки зверху вниз:
   - **Розділ 1:** Налаштування середовища та встановлення залежностей (`lightgbm`, `pytest`).
   - **Розділ 2:** Завантаження вихідного коду проєкту в ефемерну середу Colab.
   - **Розділ 3–4:** Налаштування параметрів.
   - **Розділ 5:** Запуск unit-тестів на витік даних (`pytest` — усі 15 тестів мають пройти успішно).
   - **Розділ 6–7:** Запуск walk-forward бектесту, калібрування, генерація графіків та бойового прогнозу на поточну годину.

## Особливості реалізації
- **Захист від витоку:** Повне відключення майбутніх даних через автоматичні тести `assert_no_leakage` (перевірка на інваріантність усічення).
- **Моделі:** Порівняння базових стратегій (кліматологія за годинами/днями тижня, інерція) із градієнтним бустингом (`LightGBM`) та ізотонічним калібруванням.
